"Passionné par le code ou curieux du rôle du code dans la pratique du design graphique, cet épisode est fait pour vous. Julie Blanc est designer graphique, spécialisée dans le CSS Print. Très vite, Julie nous déclare son amour pour le langage CSS. Parce que pour elle, c'est un langage graphique, il hiérarchise l'information. Elle a d'ailleurs fait une thèse pour penser les liens entre technologies du web et design graphique. En tant que théoricienne praticienne, elle s'interroge sans cesse sur les élèments de base de notre métier. Elle a d'autres priorités comme le partage des savoirs avec la communauté des codeurs : copier une ligne de code, c'est normal, diffuser ses tips est une habitude. L'open source est aussi au centre de sa pratique. Cet épisode est plus ardu que d'autre mais Julie est très pédagogue et nous explique que le code c'est aussi une manière de faire du graphisme."
